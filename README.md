## 📌 Project Overview

This project analyzes Netflix's content catalogue using **PostgreSQL** to explore patterns in Movies and TV Shows.

Through **15 business problems**, this project examines content distribution, ratings, country-wise production, genres, release trends, and other catalogue characteristics using practical SQL queries.

🎯 **Objective:** Transform structured data into meaningful insights by solving real-world business questions using SQL.

---

## 🎯 Project Objectives

- 🎥 Analyze the distribution of Movies vs. TV Shows.
- ⭐ Identify the most common content ratings.
- 🌍 Explore country-wise content distribution.
- 📅 Analyze annual content additions and release trends.
- 🎭 Investigate genres, directors, and actor contributions.
- 🔎 Explore movie durations and TV show seasons.
- 🏷️ Apply conditional logic to classify content descriptions using specific keywords.

## 🧠 SQL Concepts & Techniques

This project demonstrates the practical application of:

- 📊 **Aggregate Functions:** `COUNT()`, `MAX()`, `AVG()`
- 🔍 **Filtering & Sorting:** `WHERE`, `ORDER BY`, `LIMIT`
- 🧩 **Common Table Expressions (CTEs)**
- 🪟 **Window Functions:** `RANK()`, `AVG() OVER()`
- 🔤 **String Manipulation:** `STRING_TO_ARRAY()`, `UNNEST()`, `TRIM()`, `SPLIT_PART()`
- 📅 **Date Functions:** `TO_DATE()`, `EXTRACT()`, `INTERVAL`
- ⚙️ **Conditional Logic:** `CASE WHEN`
- 🔎 **Pattern Matching:** `ILIKE`
- 🔗 **Subqueries and Type Casting**

## 🚀 How to Run This Project

1. 📥 Clone or download this repository.
2. 🐘 Open PostgreSQL using pgAdmin or another compatible SQL client.
3. 📊 Import the Netflix dataset into a table named `netflix`.
4. ✅ Ensure the table columns match those referenced in the SQL queries.
5. 💻 Open `netflix_analysis.sql` and execute the queries individually.
